# Fonts

`Study*.woff2` are the site's web fonts: subsets of IBM Plex Sans, Serif and Mono covering the
scripts the note uses, built by `scripts/build_fonts.py` from the unchanged IBM Plex files in
`plex/`. A subset is a Modified Version under the SIL Open Font License 1.1 (`LICENSE.txt`),
whose condition 3 reserves the name "Plex", so the subsets are renamed; their name tables keep
IBM's copyright, trademark and licence notices. IBM Plex® is a trademark of IBM Corp.
